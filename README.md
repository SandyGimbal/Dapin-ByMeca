# Dapin by Meca — Layanan Pinjaman Pribadi Cepat & Terpercaya

Website resmi layanan pinjaman dana pribadi **Dapin by Meca**. Dilengkapi dengan kalkulator simulasi pinjaman dinamis, kamera foto langsung (KTP, Selfie, KK), perekam video pernyataan resmi, dan sistem cloud uploader instan untuk pengajuan cepat via WhatsApp.

## 🚀 Fitur Unggulan

- **Kalkulator Pinjaman Interaktif**: Slider dinamis untuk simulasi 10 tingkatan paket pinjaman (Rp 100.000 s/d Rp 4.000.000) dengan perhitungan pengembalian transparan.
- **Kamera Foto Dokumen Terintegrasi**: Mengambil foto fisik KTP, Selfie dengan KTP, dan Kartu Keluarga langsung dari browser dengan panduan bingkai presisi.
- **Perekam Video Pernyataan Live**: Dilengkapi teleprompter pembacaan komitmen resmi dan timer batas waktu 30 detik.
- **Cloud Storage Instant Uploader**: Otomatis mengunggah 4 berkas ke cloud storage dan menghasilkan tautan langsung untuk verifikasi Admin WhatsApp.
- **Desain Luxury & Responsif**: Tema gelap eksklusif bernuansa emas (Gold Luxury) dengan efek partikel konstelasi dinamis.
